# Homepage and Work images

The three browser workflow cards use screenshots captured from the running inquiry, support and document demos. Run `node scripts/capture-demos.mjs` against a running application to refresh them. The five technical walkthroughs retain their actual source walkthrough images and public-source or own-system labels.

The four agent project covers show recorded CI output linked to its original job. Run `node scripts/capture-recorded-runs.mjs` to verify and reproduce them. See the recorded-run provenance document for source URLs and hashes.

The hero uses a precomputed inquiry component. Stock and conceptual imagery is no longer used. Legacy asset URLs serve actual run captures for compatibility.
